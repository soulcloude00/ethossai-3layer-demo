# EthosSAI · 3-layer concept demo

Clickable, mobile-first demo of the EthosSAI 3-layer idea: **Read & Swipe**, **Listen**, **Watch & Act**, wrapped in a "Today" screen with a streak and tiny-action tracker.

- Static site, vanilla JS, no build step. State lives in `localStorage` only.
- All content is sample content. Illustrations are AI-generated; narration is AI text-to-speech (edge-tts, en-IN-NeerjaNeural).
- Episodes are motion comics (generated stills with a Ken Burns effect), not video.
- Demo only: no accounts, no payments, no analytics.
